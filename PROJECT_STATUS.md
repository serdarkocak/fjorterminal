```csharp
// ÖNCE (Hatalı - Türkçe locale'de "2406.45" → "240645")
decimal.Parse(value)

// SONRA (Doğru - Locale bağımsız)
decimal.Parse(value, CultureInfo.InvariantCulture)
```

### **2. Position Side (Hedge Mode)**
```csharp
// PlaceMarketOrderAsync
if (!string.IsNullOrEmpty(dto.PositionSide))
{
    parameters.Add("positionSide", dto.PositionSide.ToUpper());
}
```
